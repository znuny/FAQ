FAQ
=================

**Feature List**

The FAQ package is an extension providing an FAQ or rather a knowledge database.

It facilitates speeding up the knowledge transfer between agents or
(using a public web interface) between organizations and their
customers, therefore effectively saving time.

[Further information can be found here.](doc/en/feature.md)

**Prerequisites**

- Znuny 6.5

**Installation**

Download the [package](https://download.znuny.org/releases/packages/) and install it via admin interface -> package manager.

**Configuration**

See the available setting in the [System Configuration](doc/en/config.md).

**Download**

Download the [latest version](https://download.znuny.org/releases/packages/).
